怎么装、窗口上每个控件干什么、命令行怎么写、出问题先看哪里。解码与编码核心取自 SodaGray/apricot-sstv（GPL-3.0，未改动），macOS 外壳、发射端与网页版是新增代码。

一、安装与启动

cd ~/Projects/apricot-sstv-mac
make                          # 出 build/sstv-tool 与 App
cp -R "build/SSTV Tool.app" /Applications
open -a "/Applications/SSTV Tool.app"
make install                  # 可选：CLI 进 /usr/local/bin
  • 双击 App 直接进接收；桌面上有 SSTV Tool 和 SSTV 图片 两个快捷方式
  • 收的图在 ~/Pictures/SSTV Tool/，发的 WAV 在 ~/Music/SSTV Tool/
  • ad-hoc 签名按二进制哈希记权限，每次重装都会再问一次麦克风

二、接收：模式不用手选

先读 VIS 头定模式（14 种全覆盖）；VIS 丢了就退回用行同步脉冲的周期和 sync 长度锁定。 一张解完自动存图，立刻回聆听。

控件作用
收: 自动按 VIS 认，14 种都收（默认）
收: PD120只认这一种：别的 VIS 不理会，VIS 丢了也能靠同步锁
连续不等 VIS，一张解完立刻接下一张
暂停画面停住、音频照采；几秒内恢复还能接着画，停久了这张接不上（空格）
取消这张放弃当前图，已解出的部分照样存盘（X）

状态行两块：PD120 接收中 192/496 行 与 调谐 1700 Hz（偏移 −5）时钟 +3 ppm 同步 192/192 电平 −12 dBFS。 偏移是解码器测出并已补偿的频偏（±250 Hz 内自动纠），同步 x/y 是命中率，掉了就是信号不行。

三、生成：图先编辑再发

  • 拖动画面平移取景，滚轮缩放 1–3 倍
  • 旋转 90°、左右/上下翻、复位
  • 适配：留黑边（默认，保比例）/ 裁满 / 拉伸
  • 四个滑块：字号、缩放、亮度、对比
  • 文字叠加 + 九宫格位置（左下…正中…右上）
  • 预览走的就是编码器的渲染路径，看到什么就发什么

生成并播放从系统默认输出放；存成 WAV 落到 ~/Music/SSTV Tool/ 并在 Finder 里选中（想自选路径按住 Option 再点）。停止随时掐断。

四、网页版

cd ~/Projects/sstv-tool-web && make serve
# 打开 http://localhost:8765

同一套 C 核心编成 WebAssembly（44 KB）在浏览器里跑，音频图片都不出本机。 两页同构：接收（选录音或麦克风）、生成（拖拽、缩放、旋转翻转、文字）。 麦克风要 https 或 localhost。

五、命令行速查

sstv-tool 录音.wav          # 解文件，同目录出 PNG
sstv-tool --listen          # 实时接收 + 窗口
sstv-tool --listen --device 1     # --list 看设备号
sstv-tool --listen --rx-mode pd120 --continuous
sstv-tool --simulate 录音.wav     # 实时回放走链路

sstv-tool encode 图.jpg --mode pd120
sstv-tool encode 图.jpg --mode m1 --text "CQ LAN"
sstv-tool encode 图.jpg --rotate 90 --zoom 1.4
sstv-tool --send 图.jpg --mode pd120  # 开窗口发

--mode 吃名字、简写或 VIS 号（pd120 m1 s2 95 44）； --lost 12 恢复「断 12 秒就放弃」的老行为； --modes 列出本构建实际能解的模式。

八、出问题先看这里

现象先查
收不到图「电平」是否长期 −60 dBFS 以下；音源是否削顶
图提前结束默认扫完整张才结束；--lost 才提前放弃。看同步掉没掉
发出去没声WAV 峰值应在 −8.7 dBFS 左右；系统输出设备与音量
麦克风无权限系统设置 → 隐私与安全性 → 麦克风，勾上 SSTV Tool
日志在 ~/Library/Logs/SSTV Tool.log，记着 VIS、 image ended (原因)、丢样数与存图行——排查先翻它。

三步上手

  1. 载入 选择录音，或从麦克风听
  2. 等 同步数往上走，画面逐行显影
  3. 取图 解完自动存盘，回聆听等下一张

电平建议：电台 AF 开到峰值 −12 dBFS 上下；关掉 AGC、降噪和 AFC—— SSTV 解码吃的是稳定的音调与同步脉冲，压得越狠越容易认不出来。
